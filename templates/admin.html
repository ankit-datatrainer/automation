VPS Server & Production Configuration

Run the automation on your remote VPS without touching MySQL configuration.

🖥️ Server Architecture

This automation suite is built to run both on your local Windows PC (with visible Brave/Chrome browser window for manual intervention) and on a remote VPS Linux server (using headless mode or virtual display).

  • Remote MySQL: srv2203.hstgr.io:3306 (Centralized DB)
  • Port: 4140 (Web Controller & REST API)
  • Authentication: PBKDF2 HMAC-SHA256 Encrypted
  • Multi-User: Super Admin role with Operator sandboxing

🚀 1-Command VPS Deployment

On your Ubuntu/Debian VPS, clone this directory and run: 

# 1. Install dependencies
sudo apt-get update && sudo apt-get install -y python3-pip
pip install -r requirements.txt
playwright install chromium

# 2. Run service with PM2 or systemd
pm2 start app.py --name "vfs-suite" --interpreter python3
pm2 save
